# Reinforcement-Learning-Fundamentals
Reinforcement Learning (RL) is a branch of Machine Learning where an agent learns what actions to take by interacting with an environment and receiving rewards or penalties.  Unlike supervised learning, the model is not given the correct answer for every situation. It learns through trial and error.
